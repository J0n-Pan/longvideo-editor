# 长素材选句工作台 · 本机验证版

当前模型：百炼录音 `paraformer-v2`。适用于 Windows、本机单人使用，先转写长素材，再人工选句、分组并导出短片。

## 打开与启动

本机服务地址：<http://127.0.0.1:8765>。

如果页面无法打开，双击本目录 `start.cmd`。运行窗口关闭后服务停止。当前虚拟环境与 FFmpeg 放在本任务的 `work/` 中，移动交付目录时需要一起保留；本目录不是独立安装包。

已导入 `D:\test_longvideo` 中的三条素材，原视频没有复制或修改。新增素材可在页面顶部输入本机文件或文件夹路径后点击「导入素材」。

## 密钥与云转写

1. 点击「设置」，在密码框中填写百炼 API Key，点击「保存密钥」。优先使用当前 Windows 用户的凭据管理器，其次尝试用户级 DPAPI。若两者均不可用，则只保留在服务进程内存，重启后需要重填。实际方式会在设置页显示；不写入源码、数据库或报告，不使用明文凭据文件。当前受限启动环境会采用内存方式。
2. 点击「检查连接」。这一步验证临时音频上传授权，不等于完整转写已通过。
3. 首先点击「先测90秒」。人工试听文字及句子起止位置，确认音轨、中文识别、标点和专业名词符合预期。
4. 通过后点击「转写整条」。本机先提取 16kHz、单声道、64kbps MP3，再上传音频；视频留在本地。

使用百炼官方 48 小时临时音频存储用于此次验证。转写结果与音频保留本地缓存；相同音频与配置优先使用缓存或恢复已有云任务。取消已提交的任务只停止本地等待，云端仍可能执行和计费。失败的云任务记录需要排查后处理，界面不会盲目重复提交。

本轮转写估算上限为 ¥10，按照 ¥0.00008/秒估算；这是应用内防误调用限制，实际结算以百炼控制台为准。预算记录跨重启保留，不会每天自动清零。

## 选句与成片

- 点击句子文字：原片跳转播放。勾选句子后点「加入当前组」；Shift 勾选可连续选择。
- 点击「＋ 新建」创建另一条短片；每组「导出名称」可人工改名。
- 拖动组内片段改变顺序。点击 × 移除；「撤销」恢复本次页面会话内的结构调整。
- 「调整边界」允许输入原片秒数；首版依然以整句选择为主。
- 「预览当前组」按选择顺序跳播原片，供快速确认内容；正式导出的视频才是最终切点的校验依据。
- 「查看导出清单」显示实际文件名；非法文件名字符会替换，重名自动追加编号，不覆盖既有结果。
- 点击「导出当前组」或「导出全部组」，后台导出期间可继续整理分组。

输出目录：`outputs/short-clips/`。每组生成：

- `.mp4`：H.264 视频、AAC 音频，保留原显示方向和画幅，不烧录字幕。
- `.srt`：按拼接后时间重新计时的独立字幕。
- `.json`：原片路径、所选句子和字词时间戳、源区段与拼接顺序，便于回溯。

为降低切掉字头字尾的风险，导出会在选句边界前后分别预留约 80/120ms，并贴近视频帧边界。按原顺序选择的相邻原句合并为连续区段，保留中间停顿；不自动清理气口、口误、语气词或重复内容。

组的名称、顺序和边界自动保存到本机 SQLite。字幕修正只修改显示文字，原声和字词时间不变。整条重新转写会替换当前文稿；已有分组保存自己的选择快照，不会随新文稿自动重剪。

## 范围与已知限制

- 单个原视频内选句、人工分组、拖动重排。跨文件混剪、自动内容挑选、9:16 智能裁切和精剪未实现。
- 面向当前三条 H.264 素材的验证版。其他容器和编码需要另测浏览器预览兼容性；HDR 会明确拒绝导出，避免错误色彩处理。
- 当前素材编码帧为 1920×1080，但带 -90° 显示旋转，原显示画面是 1080×1920。导出按显示方向生成竖屏，未做裁切。
- 原片需保持原路径、大小和修改时间；检测到变更会要求重新导入。数据库、缓存备份时应和原片路径关系一起保存。
- ASR 的字词时间戳用于定位，不构成逐帧准确保证。边界仍需人工听看，特别是连读、长停顿、低声字尾及中英混说。
- 本机串行执行转写/导出作业，避免互相抢占资源。没有开机自启、多人协作、服务级监控和生产级部署。
- 导出临时文件在 `work/longvideo-editor-data/jobs/`，需要额外磁盘空间。建议保留数 GB 空闲并定期检查本地音频与结果缓存。

## 目录与复测

`work/longvideo-venv/` 是隔离 Python 环境；`work/longvideo-tools/paths.json` 指向已安装的 FFmpeg/ffprobe；`work/longvideo-editor-data/` 保存数据库、缓存与服务日志。

在任务根目录 PowerShell 执行：

```powershell
& work/longvideo-venv/Scripts/python.exe -X utf8 -m pytest outputs/longvideo-editor/tests -q
& work/longvideo-venv/Scripts/python.exe -X utf8 outputs/longvideo-editor/tests/verify_local_integration.py
```

集成检查使用合成色块、测试音与明确标记的模拟文稿，数据写入 `work/integration-data/`、`work/integration-exports/`，不污染真实素材项目，也不调用云服务。

依赖版本见 `requirements-lock.txt`，项目来源及元数据见 `dependency-manifest.json`。FFmpeg 来自 [Gyan 官方构建分发站](https://www.gyan.dev/ffmpeg/builds/)，其版本和许可证文本位于 `work/longvideo-tools/ffmpeg-9.0.2-essentials_build/`。

API 依据：[百炼录音 REST API](https://help.aliyun.com/zh/model-studio/paraformer-recorded-speech-recognition-restful-api)、[临时文件上传](https://help.aliyun.com/zh/model-studio/get-temporary-file-url)。

用户级 DPAPI 的行为依据 [Microsoft CryptProtectData 文档](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)。此处不启用机器范围解密。
