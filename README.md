# 长素材选句工作台

从多条视频的转写文稿中挑选句子，拼成一条短片。面向单人口播等长素材，适合人工选句和初步剪辑。

**Windows x64 · 本机剪辑 · 百炼云转写**

[下载 Windows 安装包](https://github.com/J0n-Pan/longvideo-editor/releases/download/v0.3.0-test.1/LongVideoEditor-0.3.0-test.1-windows-x64-setup.exe) · [版本与校验文件](https://github.com/J0n-Pan/longvideo-editor/releases) · [使用说明](WINDOWS-QUICKSTART.md)

当前测试版：`v0.3.0-test.1`，单文件安装／升级，内置 Python、FFmpeg 和 FFprobe，无需另装运行环境。

## 主要功能

- **自动转写**：导入视频后生成带序号和时间定位的文稿，按标点和停顿分段。
- **文稿选句**：点击播放原片，支持单句、连续句和按序号批量选择。
- **工程与素材库**：已有素材及文稿可被多个工程引用，各工程的素材清单和分组独立保存。
- **跨素材剪辑**：把不同视频的句子加入同一组，保留来源和原句序号，支持命名、排序和边界调整。
- **视频与文稿导出**：每组只生成一个 MP4；完整转写文稿可单独导出 TXT。

## 开始使用

1. 运行安装 EXE；首次选择安装位置，已有安装自动识别原位置并更新。
2. 使用桌面快捷方式或 `启动工作台.vbs` 打开工作台，无需保留命令窗口。
3. 打开“设置”，填写**自己的百炼 API Key**，选择视频和文稿的导出位置。
4. 选择或新建剪辑工程；导入新素材，或从“素材库”勾选已有素材，复用转写文稿。
5. 切换素材、选句并加入同一组，调整名称、顺序和边界；确认输出规格后预览、导出。

任务进度和错误在“后台任务”中查看。关闭网页后后台继续运行，需要停止时在“设置”中点击“退出工作台”。

## 费用与数据

- 转写调用阿里云百炼 `paraformer-v2`，费用由用户自己的百炼账户承担。
- 原视频保留在本机；提取的音频会上传百炼用于识别。项目、文稿和导出视频保存在本机。
- 测试版设有**本机累计 ¥10 的转写估算上限**，不按天重置，也不等于百炼账户额度。

## 当前范围

- 一个工程可引用多条素材，每组导出一条短片；“导出全部组”只处理当前工程。
- 每组固定输出尺寸与帧率，默认采用首条加入素材的规格；不同画幅等比缩放并补边。
- 视频编码为 H.264 / AAC，不烧录字幕；暂不支持 HDR、自动调色和响度平衡。
- 选句、分组和内容取舍由人工完成；自动剪除气口、口误、语气词及冗余语句尚未实现。
